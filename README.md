# Eder Portfolio

This is my personal portfolio developed with **Next.js**, **Tailwind CSS**, and **React**. In this project, I showcase my skills, projects, and experience as a developer. The website is designed to be fully responsive and accessible, following best web development practices.

## Features

- **Modern** and minimalist interface.
- Built with **Next.js 15** for optimization and rapid development.
- **Tailwind CSS** integration for a clean, fully customizable design.
- **Dark mode** support.
- **Responsive design**, adapting to different screen sizes.
- Dynamic, customizable content through reusable components.

## Technologies

- **Next.js 15.x**
- **Tailwind CSS 4.x**
- **React 19.x**
- **Font: Geist** (for a modern, legible typeface)

## Installation

To install and run the project locally, follow these steps:

### 1. Clone the repository
git clone https://github.com/RedeArmy/Portfolio-Next.js.git

### 2. Navigate to the project directory
cd eder-portfolio

### 3. Install the dependencies
npm install

### 4. Run the project
npm run dev
